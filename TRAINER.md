# EZPZ Trainer

Canonical standalone coaching app, separated from EZPZ Fitness on 2026-10-21. Original source: reimerskasper-creator/Ezpz-trainer/index.html. This repository contains only the Trainer application and install assets; no client records are stored in Git.

Local browser storage keys remain unchanged. Hosting under the same github.io origin retains access to existing records in the same browser. Export a backup before changing browser or domain.
